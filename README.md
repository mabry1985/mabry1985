## Josh Mabry

Product engineer. Agent systems and the interfaces people run them through. AI systems R&D at [protoLabs.studio](https://protolabs.studio).

### Agents and the tools to run them

- **[protoAgent](https://github.com/protoLabsAI/protoAgent)**: an open-source
  multi-agent framework on LangGraph. Agents run tools, hand work to subagents and
  coding agents, and remember across sessions. Built by directing AI coding agents,
  with tests and review on every change. MIT.
- **The console**: a React app for watching agents work and deciding when to step in.
- **[protoLabs design system](https://storybook.protolabs.studio)**: the components
  the console is built from, including tool cards and a command palette.
- **The completion check**: review agents that stop before they finish get a nudge or
  two, then the work is labeled incomplete.
- **[protoLab](https://github.com/protoLabsAI/protoLab)**: a self-hosted lab that
  benchmarks local models against frontier models on agent tasks.
- **[ORBIS](https://orbis.protolabs.studio)**: a voice-first companion in Rust and
  Tauri, with speech running on the device.

### Design systems and accessibility

- **[GlyphKit](https://glyphkit.design)**: 38 primitives, built with accessibility in mind, with their own
  tokens, motion and theming.
- **FEWS NET data visualization** (Phase2, 2022): accessible charts and maps for the
  famine early warning network, built to work on the web and in print.
  [Public visualization spec](https://help.fews.net/brand/visualizations).
